Nasdara Traders

This directory is being built from Nasdara’s own trader and market configuration. It is separate from Chernarus, and the catalogue is a saved configuration snapshot—not a real-time server feed.

Profile Intake // Review Before Publication

What each Nasdara profile needs

Before additional profiles are published, each trader needs a confirmed name, role, market or location, portrait, currency, inventory source, buy-from-trader and sell-to-trader permissions, and any optional lore. No Chernarus identity or location is being carried over.
