Main HUD Weather Display

When the system is enabled, your weather information is always visible on the main HUD:

  • In-game time
  • Current temperature in Celsius
  • Current season
Example HUD display · When enabled · Not live server conditions01:47 | -6°C | Winter

When enabled, the temperature shown reflects current in-game conditions, so check it regularly when deciding what clothing or supplies to take.

The Seasonal Cycle

When the mod is enabled, there are four seasons, and each lasts for 7 real-world days under the documented configuration:

  1. 01Spring7 real-world days
  2. 02Summer7 real-world days
  3. 03Fall7 real-world days
  4. 04Winter7 real-world days

When the mod is enabled and a season ends, the server automatically advances to the next one. Each season can bring different temperatures and weather conditions.

  2. Step 02

  3. Step 03

    View the Forecast

Understanding the Forecast

When enabled, the forecast shows current and upcoming conditions, including:

  • Temperature
  • Weather type and precipitation
  • Precipitation intensity or chance
  • Wind conditions and speed
  • Fog
  • Cloud coverage
  • Forecast confidence

Preparing for Changing Conditions

This advice applies to the Weather & Seasons system when enabled:

  • Check before traveling. Before a long trip, hunting expedition, loot run or mountain journey, check the forecast.
  • Dress for the conditions. Dress for the current season and expected temperatures.
  • Monitor current conditions. Watch your temperature and check the HUD regularly when choosing clothing or supplies.
  • Prepare for precipitation and wind. Use the forecast’s precipitation and wind information when planning what clothing or supplies to take.
  • Plan for a changing journey. Use the forecast to see what conditions are moving in during a long trip.
