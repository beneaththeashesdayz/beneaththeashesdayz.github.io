PC Player Guide

Updating
Your Mods

Keep your DayZ mods current so you can join Beneath the Ashes without missing files, outdated content or verification errors.

Before you start: Close DayZ completely, keep Steam open and signed in, and check #mod-updates for the exact mod update notice.

1. Check #mod-updates

When a server mod changes, the update notice is posted in Discord. Read the notice before launching the game so you know which files need attention.

2. Update with DZSA Launcher

  1. Open DZSA Launcher and select the Mods tab.
  2. Find the mod listed in #mod-updates.
  3. Click the circular-arrow Verify button on that mod’s row.
  4. Wait for verification to finish.
  5. Open the Servers tab, search for Beneath the Ashes, and click Refresh.
  6. Select the server and join.

3. Update with the Official DayZ Launcher

  1. Open DayZ from Steam and choose the Mods tab on the left.
  2. Use the Search mods field to find the mod named in the Discord notice.
  3. Outdated or missing items may be marked in red. Right-click the affected mod and choose Repair.
  4. Repeat for each mod listed in the update notice.
  5. When repairs finish, open the Servers tab and search for Beneath the Ashes.
  6. Refresh the list, select the server when it is ready, and choose Play.

4. Load Into the Server

After your mods finish verifying or repairing, refresh the server list one more time. Select Beneath the Ashes and click Play to join.

Still unable to connect? Close the launcher, unsubscribe from the affected mod in Steam Workshop, subscribe again, and let it finish downloading. If the problem continues, open a Help Ticket so staff can assist.
