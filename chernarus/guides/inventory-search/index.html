Inventory
Search

Find what you need without opening every container in Chernarus like a survivor with a very specific shopping list.

Open Inventory Search

Press O in-game to open Inventory Search and start looking through your stored items.

Keybinding: Change the key under Controls → BTA Inventory Finder. Existing test profiles may still have F7 until the key is rebound.

Search the Results

  1. Search by item name, classname, or container location.
  2. Contents appear indented beneath their containers, so you can see what is stored inside them.
  3. The location column shows where each item is stored. Select an item to see its full location.
  4. Scroll through the results when the list is longer than the visible area.

Drop an Item

Double-left-click an item to drop it at your feet.

⚠️ Container warning: Dropping a container also drops everything inside it. Check the item before clicking unless you meant to empty the whole thing onto the floor.
